One line, written as the office printer's comeback to the jams, the error
codes and the thumps — the sort of thing you would stick on the machine:

> I jammed on page 47 of your 48-page report, and yes, I chose page 47.

An entry for the [make.fun bounty](https://make.fun/bounty/u-mang-the-printer-finally-answers-8fbf0907)
"The Printer Finally Answers". The program writes the line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), standard library only.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/printer-out python3 main.py
cat /tmp/printer-out/entry.txt
```
